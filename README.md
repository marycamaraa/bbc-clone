## BBC Clone Website

A responsive news platform inspired by the BBC News website, built using React and JavaScript. The application allows users to browse news articles, search for content, and view stories by category.

### Project Goals

This project was created to:

- Strengthen React and JavaScript skills
- Practice consuming REST APIs
- Improve responsive web design techniques
- Learn frontend architecture and state management

---

### Installation
``` 
cd bbc-news-clone
npm install
npm start
```
